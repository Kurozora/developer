# KurozoraKit (Swift)

KurozoraKit is the official Swift SDK for interacting with the Kurozora API. It lets users manage their anime, manga, games, and music library and access many other Kurozora services from your app.

## Highlights

- **Async/Await** — Built on Swift Concurrency for clean, modern async code
- **97% Documentation** — Comprehensive inline documentation via Jazzy
- **Keychain Integration** — Secure token storage with KeychainAccess
- **TRON Networking** — Robust HTTP layer built on Alamofire
- **Multi-platform** — iOS 15+, iPadOS 15+, macOS 12+
- **Swift 5 & 6** — Supports both Swift language modes

## Quick Start

```swift
import KurozoraKit

// Initialize
let kurozoraKit = KurozoraKit()

// Fetch explore page
let explore = try await kurozoraKit.getExplore(genreID: 1)

// Search anime
let results = try await kurozoraKit.search(query: "Cowboy Bebop", scope: .anime)
```
