KurozoraApiClient

class KurozoraApiClient(val baseUrl: String, apiKey: String, val tokenProvider: TokenProvider? = null, val cacheManager: CacheManager? = null, val platform: Platform, userAgent: UserAgent)

The primary client for interacting with the Kurozora API.

This class handles the configuration of the HTTP client, including authentication, logging, content negotiation, caching, and error handling. It provides methods for standard HTTP verbs (GET, POST, PUT, DELETE) wrapped in a Result type.
