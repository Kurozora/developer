UserAgent

class UserAgent(appName: String = "", appVersion: String = "", appID: String = "", platformName: String = "", platformVersion: String = "")

Represents the structured user agent information for the client application.

This class is used to identify the client making requests to the Kurozora API. The information is typically formatted into a single string and sent via the User-Agent HTTP header to assist in debugging, analytics, and platform-specific logic.
