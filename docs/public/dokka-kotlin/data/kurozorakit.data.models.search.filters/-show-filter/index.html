Advanced filter criteria for querying shows (Anime, TV Series, etc.).

This model handles two primary use cases:

  1. Discovery: Searching the global database for shows based on airing schedules, technical metadata, and production details.

  2. Library Management: Filtering a user's personal collection using the trackable prefix to target shows based on personal viewing history and status.
