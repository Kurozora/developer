Filter criteria for querying literature (Manga, Light Novels, etc.).

This model supports two distinct filtering modes:

  1. Global Search: Filtering the entire database by publication metadata, counts (volume/chapter/page), and content flags.

  2. Library Search: Filtering a user's personal collection using the trackable prefix to target their personal reading status and history.
