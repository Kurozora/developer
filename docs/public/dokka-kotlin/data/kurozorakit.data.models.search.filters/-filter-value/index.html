@Serializable
data class FilterValue(val include: String? = null, val exclude: String? = null)

A utility model representing a dual-state filter value for search queries.

This class facilitates advanced filtering logic where a user can specifically request resources that possess certain traits (include) while explicitly filtering out others (exclude). It is commonly used for multi-selection filters like Genres, Themes, or Tags.
