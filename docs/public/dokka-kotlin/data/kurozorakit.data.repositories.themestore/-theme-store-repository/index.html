ThemeStoreRepository

interface ThemeStoreRepository

Data repository responsible for managing the application's visual theme marketplace.

This repository handles the retrieval of custom UI themes that users can browse and apply to the application. It provides access to both the general theme listing (storefront) and specific theme details for individual selection.
