@Serializable

The core building block of the Kurozora Discovery engine.

ExploreCategory implements a Server-Driven UI (SDUI) pattern. Instead of hardcoding the Explore tab, the application receives a list of these categories which dictate the visual hierarchy, layout constraints, and the specific type of media to be rendered.

This enables real-time updates to the "Home" or "Explore" screens (e.g., promotional banners or holiday-themed sections) without requiring a store update.
