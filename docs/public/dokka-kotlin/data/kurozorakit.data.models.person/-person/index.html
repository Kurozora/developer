Person

@Serializable
data class Person(val id: String, val type: String, val href: String, val attributes: Person.Attributes, val relationships: Person.Relationships? = null) : IdentityResource

Represents a real-world individual involved in the creation of media within the Kurozora database.

  • This includes creators such as voice actors (Seiyuu), authors, illustrators, directors, and other staff members. The model provides biographical data, social links, and their professional portfolio across different media types.
