EpisodeIdentity

@Serializable
data class EpisodeIdentity(val id: String, val type: String = "episodes", val href: String = "")

A lightweight reference to an Episode resource.

This identity model acts as a "pointer" or "handle." It is primarily used within relationship blocks (like nextEpisodes or previousEpisodes) to provide enough information to identify a resource and fetch its full details if needed, without bloating the initial JSON response with large attribute sets.
