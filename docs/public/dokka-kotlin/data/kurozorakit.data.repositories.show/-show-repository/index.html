ShowRepository

interface ShowRepository

Data repository responsible for managing and retrieving television shows and anime content.

This repository serves as the central authority for show-related data, including seasonal breakdowns, episode soundtracks, production studios, and multi-media relationships (e.g., source material or game adaptations).
