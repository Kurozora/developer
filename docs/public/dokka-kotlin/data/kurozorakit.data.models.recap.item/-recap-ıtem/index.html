RecapItem

@Serializable
data class RecapItem(val id: String, val type: String, val href: String, val attributes: RecapItem.Attributes, val relationships: RecapItem.Relationships? = null) : IdentityResource

Represents a specific data segment within a user's periodic Recap.

A RecapItem breaks down the user's consumption into categories like "Top Genres", "Most Watched Shows", or "Favorite Characters". It provides quantitative metrics (counts, duration) and links to the specific resources that defined the user's activity during that period.
