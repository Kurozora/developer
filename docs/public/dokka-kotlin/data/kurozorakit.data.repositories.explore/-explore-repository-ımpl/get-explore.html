open suspend override fun getExplore(genreId: String?, themeId: String?): Result<ExploreCategoryResponse>

Fetches the primary explore page content or a filtered view of categories.

Providing no parameters returns the global explore page, featuring staff-curated selections. If identifiers are provided, it filters the explore content specifically for that category.

Return

A Result containing the ExploreCategoryResponse with a list of curated categories.

Parameters

genreId

The unique identifier of a genre to filter the curated content.

themeId

The unique identifier of a theme to filter the curated content.

open suspend override fun getExplore(exploreCategoryId: String, next: String?, limit: Int): Result<ExploreCategoryResponse>

Retrieves the specific media items contained within a particular explore category.

Used when a user selects a "See More" option or expands a specific category (e.g., "Trending Now") to view its full paginated contents.

Return

A Result containing the ExploreCategoryResponse with detailed items for the category.

Parameters

exploreCategoryId

The unique ID of the explore category to fetch content for.

next

Pagination cursor for the next set of items in the category.

limit

The number of items to return; defaults to 5, maximum allowed is 25.
