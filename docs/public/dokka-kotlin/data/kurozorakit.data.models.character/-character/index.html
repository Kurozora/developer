Represents a fictional entity (Character) within the Kurozora database.

Characters serve as the primary junction between various media formats. This model aggregates biographical data, physical statistics, and cross-media appearances, effectively linking a single character concept to its voice actors (People) and its presence in Anime, Manga, or Games.
