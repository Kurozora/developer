LibraryImport

@Serializable
data class LibraryImport(var message: String?)

Represents the configuration and result status of a library import process.

This model is used when a user attempts to migrate their media lists from external tracking services to Kurozora. It defines the origin service, how to handle existing data conflicts, and provides feedback on the operation's outcome.
