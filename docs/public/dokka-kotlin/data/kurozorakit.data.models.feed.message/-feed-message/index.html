Represents a social post, reply, or interaction within the Kurozora Feed.

FeedMessage is a versatile resource used for top-level posts, threaded replies, and re-shares. It maintains a strict separation between content metadata (Attributes) and social context (Relationships), allowing for recursive conversation structures.
