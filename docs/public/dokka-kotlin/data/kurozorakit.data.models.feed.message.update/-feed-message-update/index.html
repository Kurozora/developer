A specialized Data Transfer Object (DTO) for mutating existing Feed Messages.

FeedMessageUpdate implements the Sparse Object Pattern. Every property is optional (nullable), allowing the client to transmit only the specific fields that have changed rather than the entire resource. This model is primarily used for:

  1. Content Modification: Updating text, HTML, or Markdown after an edit.

  2. State Toggling: Changing binary flags like NSFW, Spoiler, or Pinned status.

  3. Social Interaction: Communicating the "Heart" (Like) action to the server.

This model is the primary input for the update logic within the FeedMessage attributes, facilitating synchronization between local state and remote responses.
