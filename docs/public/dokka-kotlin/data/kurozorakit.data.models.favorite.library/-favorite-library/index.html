FavoriteLibrary

@Serializable
data class FavoriteLibrary(val games: List<Game>? = null, val literatures: List<Literature>? = null, val shows: List<Show>? = null)

A comprehensive collection of a user's favorited media across all formats.

FavoriteLibrary acts as a high-level aggregator, grouping diverse media types (Shows, Literature, Games) into a single response. This is primarily used for the "Personal Library" or "Collection" tab, allowing the UI to render multiple shelves or tabs of content without making separate API calls for each media domain.

Each list contains full resource objects rather than identities, facilitating immediate rendering of posters, titles, and progress stats.
