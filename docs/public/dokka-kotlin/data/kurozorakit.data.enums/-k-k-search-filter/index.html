KKSearchFilter

interface KKSearchFilter

A type-safe container for all possible search filters within the Kurozora ecosystem.

This sealed interface ensures that exhaustive checking is performed when processing search requests. Each entry wraps a specific domain-model filter (e.g., ShowFilter) and provides a unified way to convert these complex filters into API-ready maps.
