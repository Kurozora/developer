UserNotificationType

@Serializable
enum UserNotificationType : Enum<UserNotificationType>

Categorizes the types of push and in-app notifications a user can receive.

This enum is used by the notification handler to determine the appropriate navigation path (e.g., opening a profile vs. a feed post) and to select the correct icon and phrasing for the alert.
