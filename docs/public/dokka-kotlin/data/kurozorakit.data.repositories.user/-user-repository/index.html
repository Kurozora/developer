UserRepository

interface UserRepository

Data repository responsible for managing the authenticated user's private data and account settings.

This is the most comprehensive repository in the system, handling a wide array of user-centric features including profile management, library tracking (Anime, Manga, Games), social notifications, security sessions, and personal archives (Recaps).
