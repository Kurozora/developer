## Open Source

Kurozora believes in open source. The following repositories are publicly available:

| Project | Stars | Description |
|---------|-------|-------------|
| [kurozora-web](https://github.com/Kurozora/kurozora-web) | Backend & Web | Laravel-powered API and web interface |
| [kurozora-app](https://github.com/Kurozora/kurozora-app) | iOS/macOS | Native Apple platform client |
| [kurozora-android](https://github.com/Kurozora/kurozora-android) | Android | Native Android client |
| [KurozoraKit](https://github.com/Kurozora/KurozoraKit) | Swift SDK | Official Swift SDK |
| [kurozorakit-android](https://github.com/Kurozora/kurozorakit-android) | Kotlin SDK | Official Kotlin SDK |
| [kurozora-linux](https://github.com/Kurozora/kurozora-linux) | Desktop | Linux desktop client |

## Sponsoring

Kurozora is a free and open platform. If you find it useful, consider supporting the project:

- Star the repositories on GitHub
- Contribute code, documentation, or translations
- Spread the word in the anime community
- Subscribe to Kurozora+ in the app

## Team

Kurozora is maintained by a small dedicated team. Key areas:

- **Backend & Web** -- Laravel API, database design, web frontend
- **iOS & macOS** -- Native SwiftUI app, KurozoraKit (Swift)
- **Android & Kotlin** -- Native Android app, KurozoraKit (Kotlin), KMP architecture
- **Design** -- UI/UX, branding, visual assets
- **Community** -- Discord moderation, user support, content curation

Interested in joining? Reach out on Discord or open an issue on GitHub.
