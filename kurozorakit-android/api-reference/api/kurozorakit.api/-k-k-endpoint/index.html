KKEndpoint

sealed class KKEndpoint

A sealed class hierarchy representing all available API endpoints in the Kurozora ecosystem.

This class provides a type-safe way to construct API paths. Each subclass corresponds to a specific resource or action within the API. The path property contains the relative URL string required to make the HTTP request.
