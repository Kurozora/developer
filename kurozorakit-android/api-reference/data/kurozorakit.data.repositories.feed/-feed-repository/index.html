FeedRepository

interface FeedRepository

Data repository responsible for social feed interactions and message management.

This repository handles the retrieval of various feed types (Home, Explore) and provides comprehensive CRUD operations for feed messages. It also manages social engagements such as liking (hearting), replying to, and pinning messages.
