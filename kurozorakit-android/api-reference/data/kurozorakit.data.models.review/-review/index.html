Review

@Serializable
data class Review(val id: String, val type: String, val href: String, val attributes: Review.Attributes, val relationships: Review.Relationships? = null) : IdentityResource

Represents a user-generated review within the Kurozora ecosystem.

This model encapsulates a user's qualitative and quantitative feedback regarding various resources. A single review can be linked to almost any major entity in the database, ranging from a specific episode to a production studio or a staff member.
