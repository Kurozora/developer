interface SeasonRepository

Data repository responsible for managing and retrieving seasonal content for shows.

This repository handles the specific breakdown of television series or anime into seasons. It provides access to season-level metadata, the full list of episodes within a season, and allows users to track their overall viewing progress at the seasonal level.
