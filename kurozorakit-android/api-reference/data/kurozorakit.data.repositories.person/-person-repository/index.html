PersonRepository

interface PersonRepository

Data repository responsible for managing and retrieving information about real-world individuals.

This repository handles data for industry professionals such as voice actors, authors, directors, and staff members. It provides access to their professional biographies, the characters they have portrayed, and the media projects they have contributed to.
