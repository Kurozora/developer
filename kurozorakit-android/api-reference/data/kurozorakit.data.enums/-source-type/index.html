SourceType

enum SourceType : Enum<SourceType>

Defines the original medium from which a work was adapted.

This classification helps users identify the lineage of a series. Knowing the source is crucial for fans who may want to seek out the original material (e.g., reading the Light Novel after watching the Anime).
