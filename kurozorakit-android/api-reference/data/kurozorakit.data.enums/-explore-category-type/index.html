enum ExploreCategoryType : Enum<ExploreCategoryType>

Defines the content source and semantic meaning of an Explore section category.

This enum is used by the kurozorakit.data.repositories.explore.ExploreRepository to determine which data models to expect and how to fetch the items for a specific discovery block.
