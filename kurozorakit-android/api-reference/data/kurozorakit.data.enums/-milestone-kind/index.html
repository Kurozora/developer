MilestoneKind

enum MilestoneKind : Enum<MilestoneKind>

Defines the specific metrics used for user achievements and milestones.

This enum tracks a user's progress across various activities such as watching, reading, or playing. These milestones are often used for profile badges, level-up logic, and community leaderboards.
