Contains detailed system and hardware identifiers for a Platform.

  • These properties help identify the specific operating system and physical device characteristics. All fields are nullable to accommodate different levels of client-side reporting capabilities.

  • @property description A human-readable summary of the platform (e.g., "iPhone 13 Pro running iOS 17.1").
