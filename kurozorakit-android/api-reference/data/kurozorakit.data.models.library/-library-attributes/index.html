Tracks a user's personal interaction, progress, and preferences for a media resource.

This model is typically embedded within parent media objects (Shows, Games, Literatures). It manages the transition of states—such as moving a title from "Planning" to "Completed"—and persists user-specific metadata like personal ratings and private reviews.
