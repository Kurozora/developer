Country

@Serializable
data class Country(val name: String, val code: String, val iso31663: String)

Represents a geographical region or nation within the Kurozora ecosystem.

This model is primarily used for identifying the origin of media (e.g., Japan for Anime, South Korea for Manhwa) and for localization settings that determine which content is available in a user's specific region.
