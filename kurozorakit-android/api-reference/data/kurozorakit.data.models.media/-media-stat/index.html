MediaStat

@Serializable
data class MediaStat(val ratingCountList: List<Int>, val ratingAverage: Double, val ratingCount: Int, val rankGlobal: Int, val rankTotal: Int, val sentiment: String, val highestRatingPercentage: Double)

Encapsulates analytical statistics and engagement metrics for a media resource.

This model provides a quantitative look at how a piece of media (Show, Game, Literature) is performing within the community. It includes global rankings, weighted averages, and sentiment analysis to help users and the system gauge content quality.
