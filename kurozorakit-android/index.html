Quick Example ​

kotlin
// Initialize KurozoraKit
val kurozoraKit = KurozoraKit.Builder()
    .apiKey("your-api-key")
    .platform(myPlatform)
    .userAgent(userAgent)
    .logLevel(LogLevel.INFO)
    .cacheManager(cacheManager)
    .build()

// Fetch shows
val result = kurozoraKit.show().getShows(limit = 20)

result.onSuccess { response ->
    response.data.forEach { show ->
        println("${show.attributes.title}")
    }
}.onError { error ->
    println("Error: ${error.message}")
}

Features ​

Comprehensive Resource Coverage ​

KurozoraKit provides access to all Kurozora API resources:

  • Shows (Anime): Browse, search, and manage anime content
  • Literature (Manga/Novels): Access manga and light novel data
  • Games: Discover and track games
  • Characters: Explore character information
  • People: Access voice actors, directors, and staff data
  • Studios: Browse animation studios
  • Reviews: Read and write reviews
  • User Management: Handle authentication and user profiles
  • Search: Powerful search with advanced filtering
  • Library Management: Track user watchlists and favorites

Multi-Tier Caching ​

KurozoraKit includes a sophisticated caching system:

  • In-Memory Cache: Fast access to frequently used data
  • File-Based Cache: Persistent storage for offline support
  • Automatic Cache Promotion: Smart cache hierarchy management
  • Statistics & Monitoring: Track cache performance
  • Configurable TTL: Set custom expiration times per request

Developer Experience ​

Built with modern Android development in mind:

  • Kotlin Coroutines: Fully async with suspend functions
  • Type Safety: Comprehensive sealed classes and data classes
  • Result Monad: Elegant error handling with Result<T>
  • Builder Pattern: Flexible and intuitive configuration
  • Logging: Built-in logger with customizable levels
  • Extensible: Easy to extend with custom implementations

Installation ​
