Introduction ​

KurozoraKit lets users manage their anime library and access many other services from your app. When users provide permission to access their Kurozora account, they can use your app to share anime, add anime to their library, and discover any of the millions of anime in the Kurozora catalog. If your app detects that the user is not yet a Kurozora member, you can offer them to create an account within your app.

What is Kurozora? ​

Kurozora is an open-source anime, manga, game and music discovery service that offers unlimited access to a growing collection of over 90,000 Japanese media combined — featuring new releases, award winners, and beloved favorites. Kurozora also includes episodes, characters, voice actors, staff, studios, and much more — all without ads. You can track what you're watching, reading, playing, and listening to on iPhone, iPad, iPod touch, Mac, and through any web browser.

What is KurozoraKit? ​

KurozoraKit is the official Android SDK for the Kurozora API. It provides:

  • Type-safe API client with Kotlin coroutines support
  • Comprehensive resource access to all Kurozora data
  • Multi-tier caching system for optimal performance
  • Authentication management with token handling
  • Automatic retry logic with exponential backoff
  • Rich data models for all API responses
  • Advanced filtering and search capabilities
  • Built-in logging for debugging

Key Features ​

1. Easy Integration ​

KurozoraKit uses a simple builder pattern for configuration:

kotlin
val kurozoraKit = KurozoraKit.Builder()
    .apiKey("your-api-key")
    .platform(platformInfo)
    .userAgent(UserAgent(appName = "your_app_name", appID = "com.username.kurozora", platformName = "your_platform_name", platformVersion = "your_platform_version"))
    .logLevel(LogLevel.INFO)
    .build()

3. Type-Safe Responses ​

All responses are wrapped in a Result<T> type for safe error handling:

kotlin
when (val result = kurozoraKit.show().getShow("1")) {
    is Result.Success -> {
        val show = result.data.data.first()
        println(show.attributes.title)
    }
    is Result.Error -> {
        handleError(result.error)
    }
}

4. Advanced Caching ​

Built-in multi-tier caching with intelligent cache promotion:

kotlin
val cacheManager = CacheManager(
    caches = listOf(
        InMemoryCache(config = cacheConfig),
        FileBasedCache(cacheDir, config = cacheConfig)
    )
)

val kurozoraKit = KurozoraKit.Builder()
    .apiKey("your-api-key")
    .platform(platformInfo)
    .userAgent(UserAgent(appName = "your_app_name", appID = "com.username.kurozora", platformName = "your_platform_name", platformVersion = "your_platform_version"))
    .cacheManager(cacheManager)
    .build()

// Data is automatically cached
val result = kurozoraKit.show().getShows(limit = 20)

Architecture Overview ​

KurozoraKit is organized into several modules:

Core Module ​

Contains the main SDK entry point and configuration:

  • KurozoraKit: Main SDK class
  • KurozoraApi: API version information
  • KKServices: Additional services like secure storage

API Module ​

Handles HTTP communication with the Kurozora API:

  • KurozoraApiClient: HTTP client with retry logic
  • KKEndpoint: Type-safe endpoint definitions
  • TokenProvider: Authentication token management
  • Platform: Platform information for API calls

Data Module ​

Contains all data models and repositories:

  • Repositories: Repository interfaces and implementations
  • Models: Data classes for API responses
  • Enums: Type-safe enumerations
  • Filters: Search and filter builders

Cache Module ​

Implements the caching system:

  • Cache: Cache interface
  • CacheManager: Multi-tier cache coordinator
  • InMemoryCache: Fast in-memory cache implementation
  • FileBasedCache: Persistent disk-based cache
  • CacheStats: Cache statistics and monitoring

Shared Module ​

Shared utilities and types:

  • Result: Result monad for error handling
  • KurozoraError: Error types
  • KurozoraLogger: Logging utilities

Supported Android Versions ​

  • Minimum SDK: Android 5.0 (API level 21)
  • Target SDK: Android 14 (API level 34)
  • Kotlin Version: 2.2.0
  • Java Compatibility: Java 17

Dependencies ​

KurozoraKit uses modern Android libraries:

  • Ktor Client: HTTP client with coroutines support
  • Kotlinx Serialization: JSON serialization
  • Kotlinx DateTime: Date/time handling
  • Kotlin Coroutines: Async programming
