Person Model ​

Represents real people (voice actors, directors, writers, etc.) in the anime industry.

Structure ​

kotlin
@Serializable
data class Person(
    override val id: String,
    override val type: String,
    override val href: String,
    val attributes: Attributes,
    val relationships: Relationships? = null
) : IdentityResource

Date Handling ​

The Person model uses @Transient properties for date handling:

kotlin
@SerialName("birthdate")
val birthdateTimestamp: Long? = null

@Transient
val birthdate: Instant? = birthdateTimestamp?.let { 
    Instant.fromEpochSeconds(it) 
}

Usage Example ​

kotlin
val person: Person = // ... fetched from API

println("${person.attributes.fullName}")

person.attributes.birthdate?.let { birthdate ->
    println("Born: $birthdate")
}

person.attributes.about?.let { about ->
    println("Biography: $about")
}

// Characters voiced
person.relationships?.characters?.data?.forEach { character ->
    println("Voiced: ${character.attributes.name}")
}

// Shows worked on
person.relationships?.shows?.data?.forEach { show ->
    println("Show: ${show.attributes.title}")
}

// Websites
person.attributes.websiteURLs?.forEach { url ->
    println("Website: $url")
}
