Library Status ​

User's progress status (defined in KKLibrary.Status).

Show Status Values:

  • WATCHING: Currently watching
  • COMPLETED: Finished watching
  • ON_HOLD: Paused
  • DROPPED: Dropped
  • PLAN_TO_WATCH: Planning to watch

Literature Status Values:

  • READING: Currently reading
  • COMPLETED: Finished reading
  • ON_HOLD: Paused
  • DROPPED: Dropped
  • PLAN_TO_READ: Planning to read

Game Status Values:

  • PLAYING: Currently playing
  • COMPLETED: Finished playing
  • ON_HOLD: Paused
  • DROPPED: Dropped
  • PLAN_TO_PLAY: Planning to play

Follow Status ​

kotlin
enum class FollowStatus {
    IGNORED,
    NOT_FOLLOWING,
    PENDING,
    FOLLOWING;
    
    companion object {
        fun fromBoolean(isFollowed: Boolean?): FollowStatus {
            return when (isFollowed) {
                true -> FOLLOWING
                false -> NOT_FOLLOWING
                null -> IGNORED
            }
        }
    }
}

Usage Examples ​

Type Checking ​

kotlin
val show: Show = // ... fetched from API

// Check media type
when (show.attributes.type.name) {
    "TV" -> println("TV Series")
    "Movie" -> println("Feature Film")
    "OVA" -> println("Original Video Animation")
}

// Check status
when (show.attributes.status.name) {
    "Currently Airing" -> println("New episodes weekly!")
    "Finished" -> println("Complete series available")
}

// Get status color for UI
val statusColor = show.attributes.status.color // Hex color string

Library Status ​

kotlin
val libraryStatus = show.attributes.library?.status

when (libraryStatus) {
    KKLibrary.Status.WATCHING -> {
        println("Currently watching")
    }
    KKLibrary.Status.COMPLETED -> {
        println("Finished!")
    }
    KKLibrary.Status.PLAN_TO_WATCH -> {
        println("On your watchlist")
    }
    else -> {
        println("Not in library")
    }
}

Social Status ​

kotlin
val user: User = // ... fetched from API

// Check follow status
when (user.attributes.followStatus) {
    FollowStatus.FOLLOWING -> {
        // Show "Unfollow" button
    }
    FollowStatus.NOT_FOLLOWING -> {
        // Show "Follow" button
    }
    FollowStatus.PENDING -> {
        // Show "Request Sent"
    }
    else -> {}
}

// Check block status
if (user.attributes.blockStatus == BlockStatus.BLOCKED) {
    // User is blocked
}
